# 랜덤 선물 뽑기

연말에 카카오톡 선물하기 코드를 나누는 뽑기입니다. 
트리 아래에 선물박스를 클릭하면 랜덤으로 다른 사람의 선물코드가 나옵니다. 
자기 코드는 나오지 않고, 두 사람이 서로 교환하는 일도 없습니다.

이 앱은 **선물 돌리기**를 누르는 순간 전체 짝을 먼저 정해 두고, 화면의 뽑기는 그 결과를 보여 줍니다.

## 사용 방법

1. 참가자 이름과 그 사람의 카카오톡 선물하기 코드를 추가합니다.
2. 세 명 이상이면 **선물 돌리기**를 누릅니다. 이후에는 명단이 잠깁니다.
3. 트리 아래에 선물상자를 클릭합니다. 본인이 받은 선물코드를 확인할 수 있습니다.
4. 이미 연 이름은 다시 눌러도 같은 코드가 나옵니다.

**다시 섞기**는 짝을 새로 정하고, 이미 연 기록도 지웁니다. **명단 수정**은 배정을 취소하고 이름과 코드를 다시 고치게 합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3847](http://localhost:3847) 을 엽니다.

이름, 선물 코드, 뽑기 결과는 그 브라우저의 `localStorage`에만 저장됩니다. 다른 기기와 공유되지 않고, 사이트 데이터를 지우면 명단도 사라집니다. 그 브라우저의 개발자 도구에서는 아직 열지 않은 코드도 볼 수 있습니다.
