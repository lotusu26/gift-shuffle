# 랜덤 선물 뽑기

연말에 카카오톡 선물하기 코드를 나누는 뽑기입니다. 이름을 누르면 다른 사람의 코드가 나옵니다. 자기 코드는 나오지 않고, 두 사람이 서로 교환하는 일도 없습니다.

뽑기를 누르는 순서로 남은 선물을 나누면 마지막 사람이 자기 코드를 받을 수 있습니다. 이 앱은 **선물 돌리기**를 누르는 순간 전체 짝을 먼저 정해 두고, 화면의 뽑기는 그 결과를 보여 주는 연출입니다.

## 사용 방법

1. 참가자 이름과 그 사람이 거는 카카오톡 선물하기 코드를 추가합니다.
2. 세 명 이상이면 **선물 돌리기**를 누릅니다. 이후에는 명단이 잠깁니다. 두 명이면 서로 교환밖에 될 수 없어서 돌릴 수 없습니다.
3. 자기 이름 카드를 누릅니다. 다른 사람 이름이 잠시 돌아가다 받은 선물에서 멈춥니다.
4. 코드를 복사해 카카오톡 선물하기에서 사용합니다.
5. 이미 연 이름은 다시 눌러도 같은 코드가 나옵니다.

**다시 섞기**는 짝을 새로 정하고, 이미 연 기록도 지웁니다. **명단 수정**은 배정을 취소하고 이름과 코드를 다시 고치게 합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3847](http://localhost:3847) 을 엽니다.

`DATABASE_URL`이 있으면 Postgres에 저장합니다. 없으면 프로젝트의 `data/store.json`에 저장합니다. 이 파일은 선물 코드가 들어 있으므로 커밋하지 않습니다.
